Features

Everything a runtime needs

Declarative endpoints, built-in validation, and live observability.

Declarative endpoints

Configure with JSON instead of writing boilerplate. Schema validation built in.

12 pluggable handlers

SQL, MongoDB, SOAP, MCP, Hive, JS, FETCH, HANA, Bulk Insert, Text, Function, Function.

Access control

Public, private, bearer, and per-endpoint policies with rate limiting.

MCP & AI-native

Agents create, configure, and deploy services through model tools.

Observability

Request tracing, async job status, and runtime metrics out of the box.

Interval tasks

Cron and interval scheduling with automatic backoff and retries.
